How I work

Mostly TypeScript, occasionally Rust.

I prototype in code before I touch a Figma file. It saves a round-trip and keeps the design honest.

// A tiny render loop I keep coming back to
function frame(state) {
  const t = performance.now()
  const eased = easeOutExpo(t)

  requestAnimationFrame(() => frame({
    ...state,
    progress: eased,
  }))
}

const easeOutExpo = (x) => x === 1
  ? 1
  : 1 - Math.pow(2, -10 * x)

Code as a design tool

Most of my "design" happens in a code editor. I write components, break them, rebuild them, and only screenshot what survived.

The result: production-ready design tokens, type that actually matches the spec, and zero "let me just check Figma real quick" loops with engineering.

About

A designer who learned to code so I could stop arguing with engineers.

For the last 8 years I've been quietly building interfaces for seed-stage startups, design studios, and one research lab. I care about the small things — the way a button feels at 100ms, the rhythm of a paragraph, whether the focus ring actually shows up on a TV remote.

Before going independent in 2022, I was a senior product designer at a Series B fintech where I led the design system team. We grew the system from 30 to 200+ components and shipped it to four product surfaces.
